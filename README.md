# YashoWorld 🤖

YashoWorld is a full-stack, AI-driven chatbot application designed for fast, responsive conversational experiences. Built using a modern TypeScript/React frontend powered by Vite and a custom server backend, it provides a seamless UI for interactive AI assistants.

---

## 🏗️ Architecture & Tech Stack

* **Frontend:** Built with [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), and bundled using [Vite](https://vitejs.dev/) for high-performance client rendering.
* **Backend:** Node.js/TypeScript server environment (`server.ts`) managing API endpoints, chatbot integration, and fallback mechanisms.
* **Scripting & Utilities:** Python scripts (`add_fallback.py`, `generate_backend.py`) for automated backend configuration and dynamic route building.
* **Package Management:** Optimized for [Bun](https://bun.sh/) or Node.js (`npm`).
